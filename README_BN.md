# চক্রবাকা — বিনামূল্যের প্রথম সংস্করণ

## কী আছে
- বাংলা responsive ওয়েব অ্যাপ / PWA ভিত্তি
- রাশি পরিচিতির ১২টি কার্ড
- জন্মতথ্য ফর্ম (শুধু স্ক্রিনে সারাংশ; কুণ্ডলী গণনা করে না)
- হাতের ছবির লোকাল প্রিভিউ (সার্ভারে আপলোড করে না)
- প্রশ্ন লোকাল ডিভাইসে সংরক্ষণ
- পঞ্জিকা ও পূজা বিষয়ে সাধারণ তথ্য
- প্রাথমিক গোপনীয়তা নীতি
- অফলাইন ক্যাশের জন্য service worker

## চালানোর উপায়
`index.html` ব্রাউজারে খুললে মূল পেজ দেখা যাবে। PWA/offline সুবিধা পরীক্ষা করতে HTTPS-এ হোস্ট করতে হবে অথবা স্থানীয় development server ব্যবহার করতে হবে।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
এটি একটি কার্যকর প্রথম প্রোটোটাইপ, Play Store-এ জমা দেওয়ার জন্য প্রস্তুত AAB/APK নয়। এতে এখনো নেই:
- বাস্তব জ্যোতিষীর অ্যাকাউন্ট, লগইন বা প্রশ্ন গ্রহণের সার্ভার
- লাইভ চ্যাট/নোটিফিকেশন
- যাচাইকৃত জ্যোতির্বৈজ্ঞানিক পঞ্জিকা বা জন্মকুণ্ডলী গণনা
- ব্যাকআপ, moderation, abuse reporting এবং production security review
- Android package, signing key ও Play Console release configuration

Play Store-এ প্রকাশের আগে ডোমেইন/HTTPS hosting, production backend, data-safety disclosure, পূর্ণ privacy policy, app icon/screenshots, Android wrapper/TWA বা native Android build, signing এবং Play Console testing প্রয়োজন। Play Console অ্যাকাউন্ট ও প্রকাশনা একজন প্রাপ্তবয়স্ক অ্যাকাউন্ট-মালিকের মাধ্যমে করতে হবে।

## ছবি
